# data.json ドキュメント

日本の主要なスーパーマーケット業界団体（7団体）から収集したスーパーマーケット企業情報の構造化データです。

## 概要

- **ファイル**: `data.json`
- **形式**: JSON 配列
- **レコード数**: 735件
- **生成方法**: `uv run python main.py`

## データ構造

各レコードは以下の5つのフィールドで構成されます。

| フィールド | 型 | 説明 | 例 |
|---|---|---|---|
| `prefecture` | string | 都道府県名（日本語） | `"北海道"` |
| `company_name` | string | 企業名（日本語） | `"(株)西條"` |
| `company_url` | string または null | 企業の公式サイトURL | `"https://www.saijo-dp.co.jp/"` |
| `supermarket_names` | string[] | 運営するスーパーマーケットのブランド名リスト | `["西條", "BESTOM", "Qマート"]` |
| `location` | string または null | 所在地（住所） | `"北海道磯谷郡蘭越町蘭越町１０７番地２"` |

### レコード例

```json
{
  "prefecture": "北海道",
  "company_url": "http://www.saijo-dp.co.jp/",
  "company_name": "(株)西條",
  "supermarket_names": [
    "西條",
    "BESTOM",
    "Qマート"
  ],
  "location": null
}
```

## フィールド詳細

### prefecture
都道府県名。全47都道府県に加え、海外企業を示す `"海外"` も存在します。

### company_url
企業の公式サイトURL。取得できなかった場合は `null`、または空文字 `""` の場合があります。

### supermarket_names
企業が運営するスーパーマーケットのブランド名の配列。ブランド情報が取得できなかった場合は空配列 `[]` となります。

### location
企業の所在地。住所情報が取得できたレコードのみ値を持ち、それ以外は `null` です（735件中67件に値あり）。住所の数字は全角で表記されています。

## データの性質

- 各フィールドは取得元（業界団体の会員リストなど）により欠損する場合があります
- `company_url` と `location` はどちらか一方のみ、あるいは両方持つ場合があります
- 同じ都道府県に複数の企業が登録されています（例: 東京都 91件）

## データソース

以下の7つの日本スーパーマーケット業界団体から収集されます。

1. 全国スーパーマーケット協会 (NSAJ)
2. 日本スーパーマーケット協会 (JSA)
3. オール日本スーパーマーケット協会 (AJS)
4. 日本チェーンストア協会 (JCSA)
5. シジシージャパン (CGC)
6. 日本流通産業 (Nichiryu)
7. 協同組合セルコチェーン (Selco)
